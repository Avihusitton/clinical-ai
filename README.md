# Clinical AI Workspace

מערכת AI קלינית לניהול ועיבוד שיחות למטפלים.

## ארכיטקטורה
המערכת פועלת במודל היררכי של 3 רמות:
1. **Therapist (מטפל):** ברמת השורש - לכל מטפל יש מזהה ייחודי.
2. **Patient (מטופל):** תחת כל מטפל יכולים להיות מספר מטופלים.
3. **Conversation (שיחה):** תחת כל מטופל מקוטלגות השיחות, העיבודים הקליניים והזיהויים.

מסד הנתונים הגרפי (Neo4j) מאחסן את הקשרים והישויות, בעוד פייתון משמש לעיבוד הנתונים ולממשק המשתמש (UI).

## דרישות קדם
- **Python 3.10+** 
- **Neo4j** (גרסה 5.19 ומעלה או חיבור לענן AuraDB)
- חשבון **OpenRouter** (לגישה למודלי LLM)

## הרצה בסביבת פיתוח מקומית (Development)

1. העתק את הקובץ `.env.example` לקובץ חדש בשם `.env` והזן את הערכים שלך.
2. ודא ש-Neo4j Desktop פועל מקומית.
3. הרץ את הקובץ: `start_local_system.ps1` באמצעות PowerShell.
4. האפליקציה תהיה זמינה בכתובת: `http://127.0.0.1:8765`

## פריסה בענן - מסודרת וחינמית (Production Cloud)

כדי לאחסן את הפרויקט בצורה מסודרת וחינמית ללא צורך בניהול שרתים, נשתמש בשירותים מנוהלים (PaaS):

### 1. מסד נתונים (Neo4j AuraDB)
- פתח חשבון חינמי ב-[Neo4j AuraDB](https://neo4j.com/cloud/platform/aura-graph-database/).
- צור מסד נתונים חינמי. קבל את ה-URI (שמתחיל ב-`neo4j+s://`) ואת הסיסמה.
- עדכן את המשתנים `NEO4J_URI` ו-`NEO4J_PASSWORD` בשרת שלך בהתאם.

### 2. אחסון האפליקציה ב-Render
- פתח חשבון חינמי ב-[Render](https://render.com/).
- חבר את הרפוזיטורי שלך מ-GitHub.
- בחר יצירת **Web Service**. Render יזהה אוטומטית את ה-`Dockerfile` ויריץ את הפרויקט בחינם.
- תחת הגדרות הסביבה (Environment Variables) ב-Render, הכנס את כל הערכים מתוך ה-`.env` שלך.
- קוד המערכת כבר מוגדר להאזין אוטומטית למשתנה הסביבה `PORT` ש-Render מספק.

### 3. חיבור הדומיין (Cloudflare)
- תחת הגדרות ה-Web Service ב-Render, תוכל להוסיף את הדומיין המותאם אישית שלך.
- ב-Cloudflare, פשוט הוסף רשומת CNAME שמפנה אל כתובת ה-`.onrender.com` שקיבלת. 
- Cloudflare ימשיך לנהל את האבטחה, ה-SSL והניתוב, בעוד השרת הפיזי מתארח בחינם.

## רכיבים מרכזיים
- `local_qa_app.py` - שרת ה-API המרכזי.
- `clinical_workspace_ui.py` - ממשק המשתמש הקליני.
- `ingestion_pipeline.py` - תהליך קליטת הטקסטים והמסמכים ל-Neo4j.
- `conversation_store.py` - ניהול הגישה למסד הנתונים וההיררכיה הקלינית.
